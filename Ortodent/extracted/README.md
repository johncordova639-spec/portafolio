# Logodent

Landing page para marca dental premium, preparada para publicación.

## Propiedad

Este proyecto es propiedad del cliente y queda listo para uso comercial y publicación.

## Desarrollo local

```sh
npm install
npm run dev -- --host 0.0.0.0 --port 3000
```

## Producción

```sh
npm run build
```

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
