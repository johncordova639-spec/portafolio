# Instrucciones del proyecto

Este proyecto es propiedad del cliente y está preparado para publicación comercial.

- Mantén la marca, textos y estilo alineados con la identidad de Logodent.
- Evita referencias a herramientas o plataformas externas de generación.
- Prioriza claridad, confianza visual y llamadas a la acción para conversión.
- Guarda la app en un estado limpio y funcional antes de publicar.
